Incluye

  • Dominio propio bajo marca del cliente (propiedad del cliente).
  • HTTPS automático (candado SSL) en el navegador.
  • Publicación segura con Cloudflare Tunnel (sin abrir puertos).
  • DNS y protección básica Cloudflare Free.
  • Entrega de accesos/credenciales de la cuenta Cloudflare al cliente (si aplica).

No incluye

  • Diseño o desarrollo adicional de la tienda.
  • Hosting en VPS/datacenter dedicado (este presupuesto usa publicación vía túnel en equipo local).
  • Correo corporativo (@dominio) — se puede cotizar aparte (p. ej. Google Workspace / Zoho).
  • Plan Cloudflare Pro (USD 20/mes) u otros add-ons de pago.
  • Disponibilidad 24/7 garantizada tipo SLA de datacenter.
Costos recurrentes (a cargo del cliente)
  • Renovación del dominio .com: ≈ USD 10.50 – 12.00 / año (precio Cloudflare a costo, sujeto a tarifa del registro).
  • Cloudflare Free + Tunnel: USD 0 / mes.
  • Opciones de dominio alternativas (referencia Cloudflare): .org ≈ USD 8.50, .net ≈ USD 11.86, .co ≈ USD 30.00 / año.

Condiciones de pago

  • 50% al aceptar el presupuesto (reserva + registro del dominio).
  • 50% al entregar el sitio accesible por HTTPS con el dominio configurado.
  • El dominio queda a nombre del cliente; el gasto de registro se factura o se reembolsa contra recibo.
  • Tiempo estimado de entrega: 1–2 días hábiles tras confirmación del nombre de dominio disponible.
